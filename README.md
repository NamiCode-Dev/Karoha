# Karoha for Android

Karohaは、SNS「Karotter」をAndroidから利用するための非公式クライアントです。

Karotterの投稿、ストーリー、コミュニティ、掲示板、DMなどを一つのアプリにまとめ、Material Components / Compose Materialに依存しない独自UIで実装しています。Paper、Snow、Mistのカラーテーマと、それぞれのライト・ダーク表示に対応しています。

> [!IMPORTANT]
> KarohaはNamiCodeが提供する非公式アプリです。Karotterの公式アプリではなく、Karotter運営との提携・承認を示すものではありません。サービス側の仕様変更などにより、一部機能が利用できなくなる場合があります。

- ページングによる無限スクロール

- いいね、ブックマーク、絵文字リアクション

- Karotter公式カタログから取得する絵文字と、画像型のProリアクション
- 画像、動画、音声、GIFの表示
- 画面内の動画・GIFの自動再生と動画のミュート切り替え
- 画像の全画面表示、ピンチ拡大、複数画像の左右スワイプ、長押しメニューからの保存
- 画像スポイラーと「センシティブなメディア」表示
- 投票の表示・投票
- Markdown、Markdown画像・画像リンク、KaTeX、ルビ、URL、`@ユーザー名`、`#ハッシュタグ`
- `||文字||`形式の文字スポイラー
- URLのリンクプレビュー
- 長文の折りたたみ表示
- 投稿詳細、返信元・返信一覧、引用元
- 表示数、ブックマーク数、反応したユーザー・引用投稿の一覧

- 投稿の編集、削除、固定

- プランに応じた文字数制限（FREE: 200文字、PLUS: 500文字、PRO: 1000文字）

- 添付画像ごとのスポイラー設定

- 最低年齢・最高年齢のプリセットおよびカスタム入力

- 折りたたみ式Markdown入力補助と投稿プレビュー
- 入力中のハッシュタグ・ユーザー名の色分け
- 編集中に閉じる場合の確認

### ストーリー

- 画像・動画ストーリーの作成
- キャプションの文字色、背景、サイズ、位置調整

- Proプロフィール色とカード装飾
- 複数の固定投稿
- 「投稿」「返信」「メディア」「いいね」タブ

- フォロー中、フォロワー、知り合いのフォロワー一覧

- 「メッセージ」「リクエスト」のタブ切り替え

### 通知

- 通知一覧と種類別フィルター

- 認証を復旧できない場合はエラー通知後に監視を一時停止

## 認証とデータ保護

- アクセストークン、Cookie、CSRFトークン、KarotterのセッションIDを端末内に保持します。
- 保存を選択したログイン情報は、Android Keystoreの非エクスポート鍵を使用したAES-GCMで暗号化します。
- 通常は記録済みセッションを再利用し、不要なログインセッションの増加を抑えます。
- 通常ログインと認証アプリの6桁コードを使う二段階認証に対応しています。二段階認証コードは保存しません。
- 認証に失敗した場合は、セッション延長、記録済みセッションの復帰、自動再ログインの順で復旧を試みます。
- 自動再ログインには間隔制限があり、一時的な通信エラーだけで新しいセッションを作成し続けないようにしています。
- ネットワーク接続がない場合はAPIリクエストや自動ログアウトを行わず、再試行画面を表示します。
- ユーザー名やパスワードをソースコードへ埋め込む必要はありません。認証情報をリポジトリへ追加しないでください。

## Android権限

| 権限 | 用途 |
| --- | --- |
| `INTERNET` | Karotter APIとメディアへの接続 |
| `ACCESS_NETWORK_STATE` | オフライン判定と不要なAPI通信の抑止 |
| `POST_NOTIFICATIONS` | Android 13以降のシステム通知 |
| `FOREGROUND_SERVICE` | バックグラウンド通知確認 |
| `FOREGROUND_SERVICE_REMOTE_MESSAGING` | 通知確認用フォアグラウンドサービス |
| `REQUEST_IGNORE_BATTERY_OPTIMIZATIONS` | ユーザーが許可した場合の通知監視安定化 |
| `RECEIVE_BOOT_COMPLETED` | 端末再起動後のバックグラウンド通知監視の復帰 |
| `REQUEST_INSTALL_PACKAGES` | GitHub Releasesから取得した更新APKのインストール |

バッテリー最適化の除外は任意です。端末メーカーの省電力設定によっては、除外後もバックグラウンド通知が遅延・停止する場合があります。

## ビルド

### 必要なもの

- Android Studio
- Android SDK 35
- JDK 17
- Android 8.0以上の実機またはエミュレーター

`local.properties`にAndroid SDKの場所を設定します。このファイルはGit管理対象外です。

```properties
sdk.dir=C\:\\Users\\your-name\\AppData\\Local\\Android\\Sdk
```

デバッグAPKを作成します。

```powershell
.\gradlew.bat assembleDebug
```

生成先:

```text
app\build\outputs\apk\debug\app-debug.apk
```

接続中の端末へインストールする場合:

```powershell
adb install -r app\build\outputs\apk\debug\app-debug.apk
```

## プロジェクト構成

```text
app/src/main/java/social/karotter/client/
├── MainActivity.kt
├── KarotterApplication.kt
├── AppUpdateManager.kt
├── BackgroundNotificationService.kt
├── data/
│   ├── CredentialVault.kt
│   ├── KarotterApi.kt
│   └── NetworkConnectivity.kt
└── ui/
    └── KarotterApp.kt
```

- `KarotterApp.kt`: 画面、独自UIコンポーネント、ナビゲーション、アニメーション
- `AppUpdateManager.kt`: GitHub Releasesの確認、APKのダウンロード・検証・インストール
- `KarotterApi.kt`: API通信、JSON解析、セッション・Cookie・CSRF管理
- `CredentialVault.kt`: 複数アカウントの認証情報をAndroid Keystoreで暗号化
- `NetworkConnectivity.kt`: 検証済みインターネット接続の判定
- `BackgroundNotificationService.kt`: アプリがバックグラウンドのときの通知確認

## 注意事項

- Karotter側の仕様変更や提供状況により、一部またはすべての機能が予告なく利用できなくなる場合があります。
- Proユーザー向け機能は現在開発中です。NamiCodeがProプランを利用しておらず、実際のPro環境で十分な動作確認を行えていないため、Pro設定、プロフィール装飾、複数固定投稿、コミュニティ作成などで、表示や操作が正しく反映されない場合があります。
- 非公開アカウント関連機能は現在開発中です。フォローリクエスト、プロフィール・投稿の公開制御、フォロー一覧などで、不具合が発生する可能性があります。
- 一部の機能は、アカウントの公開範囲、フォロー関係、年齢設定、Pro契約、コミュニティ参加状態などにより表示・実行できません。
- 自動更新は画面の表示状態とネットワーク接続を考慮して動作します。OSの省電力制御下では正確な間隔が保証されません。
